## 📘 Topics Covered  

### 🔹 Linux  
- **Conceptual Topics**:  
  - Linux vs Unix, file system hierarchy, paths (absolute & relative)  
  - File permissions, ownership, symbolic vs hard links  
  - `umask`, inodes, standard I/O redirection  
  - Commands: `grep`, `cut`, `awk`, `find`, `sed`, `df`, `du`, `ps`, `top`, `htop`  
  - Package management (`apt update/upgrade/install`)  
  - Cron jobs, environment variables, process states  

- **Practical Topics**:  
  - File & directory operations (create, copy, rename, sort, merge)  
  - Text processing (`cut`, `sort`, `sed`)  
  - Disk/memory usage & monitoring processes  
  - Archiving & compression (`tar`, `zip`, `gzip`)  
  - User management & permissions (`chmod`, `chown`, `sudoers`)  
  - Cron jobs & automation scripts  

---

### 🔹 Python  
- **Conceptual Topics**:  
  - Variables vs constants, data types (list, tuple, set, dict, string)  
  - Mutable vs immutable, indexing & slicing  
  - Operators (identity, membership, comparison)  
  - Methods for strings, lists, sets, and tuples  

- **Practical Coding**:  
  - Basic string/list/tuple/set operations  
  - Loops, conditions, input/output handling  
  - Removing duplicates, concatenation, joining/splitting strings  
  - Even number filtering, tuple/list conversion, union & intersection of sets  

- **Scenario-Based Problems**:  
  - Sales total & average calculation  
  - Filtering filenames & city names  
  - Handling duplicates in lists and sets  
  - Checking substring existence in strings  
  - Removing log messages, set operations on customer IDs  

---

### 🔹 SQL  
- **Conceptual Topics**:  
  - SQL basics: DDL, DML, DCL, TCL  
  - Keys, constraints, normalization, ACID properties  
  - Joins (INNER, LEFT, RIGHT, FULL, SELF, CROSS, SEMI, ANTI)  
  - Indexing (clustered, non-clustered, composite)  
  - Views vs materialized views, stored procedures vs functions  
  - Window functions (RANK, DENSE_RANK, ROW_NUMBER, LEAD, LAG)  
  - OLTP vs OLAP databases  

- **Practical Queries**:  
  - Creating tables, inserting sample data  
  - Filtering with `WHERE`, `LIKE`, `BETWEEN`, `IN`  
  - Aggregations (`SUM`, `AVG`, `COUNT`, `MAX`, `MIN`)  
  - Joins (INNER, LEFT, RIGHT, SELF)  
  - Ranking, running totals, subqueries & CTEs  
  - Set operations (`UNION`, `INTERSECT`, `EXCEPT`)  
  - Index creation & execution plans  
  - Transactions (`COMMIT`, `ROLLBACK`, `SAVEPOINT`)  
  - Date & string functions  

- **Scenario-Based SQL**:  
  - **Employee Database** – salary analysis, department-based queries  
  - **E-commerce Orders** – customer orders, top spenders, date filtering  
  - **School Database** – marks & class-based analysis  
  - **Banking Transactions** – credits, debits, balances, net transactions  
  - **Movie Database** – actor/movie relationships, ratings, multi-actor filtering
